# 职位系统（职位 / 武器类别 / 插槽）

> 需求：为角色添加职位设定（剑士 / 法师 / 枪手），职位决定角色只能装备对应武器类别，
> 且不同职位的武器吸附插槽不同。

## 一、三个新概念

| 概念 | 枚举 | 值 | 说明 |
|------|------|-----|------|
| **职位** Job Class | `EJobClass` | `BladeMaster` 剑士 / `Mage` 法师 / `Gunner` 枪手 | 角色蓝图设置，决定可用武器类别与插槽 |
| **武器类别** Weapon Category | `EWeaponCategory` | `LightBlade` 轻剑 / `MagicTool` 法器 / `Firearm` 枪械 | 武器蓝图设置，决定职位归属、近战/远程、插槽 |
| **插槽** Socket | `FName` | `HandGrip_R` / `magic_WeaponSocket` | 按职位自动套，无需武器蓝图各自填 |

## 二、映射关系（唯一真相源：`FJobWeaponRules`）

| 职位 | 可用武器类别 | 吸附插槽 |
|------|------------|---------|
| 剑士 BladeMaster | 轻剑 LightBlade | `HandGrip_R` |
| 法师 Mage | 法器 MagicTool | `magic_WeaponSocket` |
| 枪手 Gunner（占位） | 枪械 Firearm | `HandGrip_R` |

映射代码位置：`WeaponBase.h` 的 `FJobWeaponRules`（`GetCategoryForJob` / `CanJobUseCategory` / `GetSocketForJob`）。

## 三、怎么用（0 基础版）

### 1. 设置角色职位
打开 `BP_PlayerCharacter` → 右侧 Details → 搜 **Job** → 找到 **Job Class** → 选剑士 / 法师 / 枪手。

### 2. 设置武器类别
打开武器蓝图（如 `Content/characters/arms/sword.uasset`、`test_knife.uasset`）→
Class Defaults → 搜 **Weapon** → 找到 **Weapon Category** → 选轻剑 / 法器 / 枪械。

> ⚠️ **必须显式填**：`WeaponCategory` 默认值 0 = `LightBlade`（轻剑）。
> 新武器蓝图若不填类别，会被当成「轻剑」，从而被「剑士」职位放行。
> 与 `kind_tool` 默认 0 = 武器 是同一种坑。

### 3. 插槽不用管
装备时 C++ 自动按职位套插槽（法师 → `magic_WeaponSocket`，其余 → `HandGrip_R`），
武器蓝图的 `Attach Socket Name` 会被覆盖，无需各自填。

## 四、约束行为

### 1. 装备拦截
`ABattleCharacter::EquipWeapon` 在 Spawn 前校验武器类别是否匹配当前职位。
不匹配 → 拒绝装备 + 打日志（含「改职位」或「改武器类别」两种修法）。
所有装备路径（开局 `DefaultWeaponClass`、武器背包点格子、蓝图直接调 `Equip Weapon`）都走这一个入口，约束全局生效。

### 2. 武器背包列表过滤
武器模式下，列表在「IsWeaponItem 过滤」之后再做一层职位过滤：
- 类别匹配职位的武器 → 保留
- 类别不匹配、但能解析出武器蓝图类的 → 剔除（打日志）
- 解析不出武器蓝图类的 → 保留（装备时再拦，避免列表误伤）

### 3. 空列表安全阀（与 fail-closed 教训一致）
- **IsWeaponItem 过滤**把列表清空 → 判定据出错，**回退放行** + 警告。
- **职位过滤**把列表清空 → 属「合法空」（如枪手暂无枪械武器），**不回退**，打日志说明
  「这个职位还没有可用武器，改职位即可」。

### 4. 切换职位自动卸下
`SetJobClass` 切换职位后，若当前武器不属于新职位 → 自动卸下（空手），
避免「法师手上拿着剑」的非法状态。

## 五、关键函数

| 函数 | 位置 | 作用 |
|------|------|------|
| `FJobWeaponRules::GetCategoryForJob` | WeaponBase.cpp | 职位 → 可用武器类别 |
| `FJobWeaponRules::CanJobUseCategory` | WeaponBase.cpp | 职位能否用某类别 |
| `FJobWeaponRules::GetSocketForJob` | WeaponBase.cpp | 职位 → 插槽名 |
| `AWeaponBase::GetSocketNameForCategory` | WeaponBase.cpp | 武器类别 → 插槽名 |
| `AWeaponBase::GetWeaponCategory` | WeaponBase.h | 读武器类别 |
| `AWeaponBase::IsRanged` | WeaponBase.cpp | 是否远程（法器=远程） |
| `ABattleCharacter::SetJobClass` | BattleCharacter.cpp | 设置职位（含自动卸下） |
| `ABattleCharacter::CanUseWeaponCategory` | BattleCharacter.cpp | 类别是否匹配职位 |
| `ABattleCharacter::CanEquipWeaponClassForJob` | BattleCharacter.cpp | 武器蓝图是否匹配职位 |
| `ABattleCharacter::ResolveEquipSocketName` | BattleCharacter.cpp | 装备时解析插槽名 |

## 六、日志前缀

- 装备拦截 / 插槽覆盖 / 列表过滤 → `[Job]`
- 原有武器背包逻辑 → `[Arm]`

排查「武器装不上」时先看 `[Job]` 日志，它会明确写「类别 X 与职位 Y 不匹配 + 怎么修」。
