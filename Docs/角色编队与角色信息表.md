# 角色编队系统（角色面板切人 + L 键编队）

> 需求：① 参考《鸣潮》角色面板的切人方式，`WBP_Character_imf` 的 `chara_pitc_head` 下
> 按拥有的角色自动生成头像按钮（含选中框）；② 按 **L** 键打开角色编队（唤起鼠标），
> 左侧数字=不同队伍，「快速编队」按 1~3 顺序点选角色，完成后逐位覆盖/填充；
> ③ 角色列表统一由数据表 `Data_chara_imfor` 同步（角色面板与编队共用）。

## 一、功能总览

| 功能 | 入口 | 实现 |
|------|------|------|
| 角色面板自动头像 | 打开角色面板（C 键）→ `chara_pitc_head` | C++ 运行时生成头像按钮 + 金色选中框 |
| 角色编队 | **L 键** | 纯 C++ 构建界面（无需 WBP），暂停游戏 + 唤起鼠标 |
| 快速编队 | 编队界面右下按钮 | 头像网格按顺序点选 1/2/3 →「完成」写回队伍 |
| 角色列表同步 | `Data_chara_imfor` 数据表 | 面板头像、编队立绘槽、快速编队网格三处共用 |

## 二、建表步骤（0 基础点击级）

1. Content 浏览器 → 右键 → **其他（Miscellaneous）→ 数据表（Data Table）**
2. 「Pick Row Structure」里选 **Chara Info Entry**（中文界面显示同名结构）→ 确定
3. 命名为 **`Data_chara_imfor`**，放在 **`Content/UI/chara_imf/`** 目录下
   （C++ 默认从这里懒加载；放别处也可以，在 BP_PlayerCharacter → Character|CharaInfo →
   **Chara Info Table** 里手动指定）
4. 双击打开，**点「添加」按钮加行**，每行填一个角色：

| 列 | 填什么 |
|----|--------|
| 行名（Row Name） | 角色唯一标识，如 `player`、`magic`（编队数据记的就是它） |
| Chara Class | 该角色的蓝图类（下拉选 `BP_PlayerCharacter` / `BP_Chara_magic` …） |
| Chara Name | 显示名（如 `绯雪`） |
| Head Icon | 头像图（UTexture2D）——面板头像按钮、快速编队网格用 |
| Portrait | 立绘大图（可留空，留空则编队立绘槽用头像显示） |

5. 保存。**完成** —— 角色面板头像、编队立绘槽、快速编队列表立即全部生效。

## 三、角色面板切人（chara_pitc_head）

- 打开面板（C 键）时 C++ **清空 `chara_pitc_head` 容器**（含 WBP 里硬编码的 `chara_1`/`chara_2`），
  然后按「拥有的角色」自动生成头像按钮：
  - 按钮 = 头像图 + 金色选中框（运行时构造 Border 描边，无需贴图资产）
  - 点击头像 → 面板属性/立绘切换到该角色；当前选中的头像显示金框
- 「拥有的角色」判定：
  - `BP_PlayerCharacter → Character|CharaInfo → Owned Chara Rows` **留空 = 表里全部角色**（最省配置）
  - 非空 = 只显示列表里的行名（将来做角色解锁/获取时用）
- **兼容**：还没建 `Data_chara_imfor` 时，回退旧的 `Character Slot Classes` 数组行为（已填的配置不丢）；
  WBP 里 `chara_pitc_head` 容器被改名/删除时，回退旧的 `chara_1~4` 硬编码按钮绑定。

## 四、角色编队（L 键）

- **L 键**开/关编队界面（运行时自建输入映射，无需编辑器建 IA/IMC 资产，与 B 键同模式）。
- 打开时：暂停游戏 + **唤起鼠标**（UIOnly 输入模式）；与角色面板/背包互斥（自动先收起对方）。
- 界面布局（参考《鸣潮》）：
  - 左上标题「队伍 N」
  - **左侧数字列 = 不同队伍**（1~8，点击切换查看；当前队金色高亮）
  - 中间 3 个立绘槽：立绘 + Lv + 名字（成员为空显示「空」）
  - 右下「快速编队」按钮 +「已出战」灰色状态标签
  - （截图里立绘槽底部的装饰图标条 = 红框内容，按要求未制作）

## 五、快速编队

1. 编队界面点「**快速编队**」→ 覆盖出角色列表（拥有角色的头像网格，每行 8 个）
2. **按点击顺序选择**：第 1 次点 = 1 号位，第 2 次 = 2 号位，第 3 次 = 3 号位
   （对应编队界面**从左往右**的槽位）；已选的再点一次 = 取消（编号前移）
3. 点「**完成**」→ **逐位写回当前队伍**：
   - 第 i 位选了角色 → **覆盖**队伍第 i 位（原来有人也覆盖）
   - 第 i 位没选 → 队伍第 i 位**保持原样**（队伍原本为空就仍是空，「为空就填充」）
   - 例：队伍原 [绯雪, 空, 洛瑟菈]，本次只选了 2 个（穆穆、+第 2 个）→ 结果 [穆穆, 第2个, 洛瑟菈]

## 八、已知边界

- 头像/立绘没配贴图时显示灰色占位块（功能不受影响，配图即好）
- 编队界面当前是纯 C++ 布局（可用、不花哨）；后续要美化时做一个 WBP 传入即可，
  不用动交互逻辑
- 「已出战」为静态状态标签（截图同位置还原），暂不与实际出战角色联动
- 技能/大招不会因编队切换而改变 —— 编队当前只是「数据 + UI」层；
  切换操控角色（把编队角色 Spawn 进世界）是下一步的事，需要时说一声
